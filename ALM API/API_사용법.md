# 완전판매 진단 시스템 (Streamlit)

## 실행

1. `.env`에 `OPENAI_API_KEY`를 설정합니다. 기존 `.env`를 그대로 사용할 수 있습니다.
2. `run.bat` 또는 `run_alm.bat`을 실행합니다. 필요한 패키지가 없으면 `.venv`를 만들고 `requirements.txt`의 패키지를 설치합니다. 이미 앱이 실행 중이면 기존 화면을 엽니다.
3. 브라우저에서 `http://127.0.0.1:18766`으로 열린 Streamlit 화면을 사용합니다.
4. MP3를 업로드하고 회원번호·판매일자를 확인한 뒤 **MP3 업로드 후 검토**를 누릅니다.

## 처리 기능

- 파일명 `회원번호_YYYYMMDD.mp3`에서 회원번호와 판매일자를 읽어 입력란에 자동 설정합니다. 예: `M260001_20260105.mp3` → `M260001`, `2026-01-05`.
- 회원번호와 판매일자가 `녹취찾기_대상리스트.xlsx`에 있는지 확인하고, 파일명과 대상 목록의 녹취파일명(열이 있으면)을 대조합니다.
- MP3 음성을 한국어 텍스트로 변환합니다.
- 음성 변환이 끝나는 즉시 녹취 텍스트를 화면에 표시합니다. 이후 검토가 실패해도 같은 파일의 텍스트를 유지하고 재시도에 재사용합니다.
- `표준스크립트.txt`의 번호 항목별로 근거와 누락사항을 정리하고 최종 결과를 표시합니다.
- 결과는 `완전판매 기준 충족`, `불완전판매(불판) 위험`, `판정 보류` 중 하나입니다. 검토 결과가 모호하면 판정을 보류합니다.
- 업로드 파일은 로컬 디스크에 저장하지 않습니다. 최대 크기는 25MB입니다.

## 필요한 파일 및 모델

- `녹취찾기_대상리스트.xlsx`: `회원번호`, `판매일자` 열이 필요합니다. `상담원 사번`, `상품명`, `녹취파일명`은 선택 사항입니다.
- `표준스크립트.txt`: 검토 기준 문서입니다.
- `.env`: `OPENAI_API_KEY`가 필요합니다. 음성 변환 모델은 `OPENAI_TRANSCRIPTION_MODEL`(기본 `gpt-4o-mini-transcribe`), 검토 모델은 `OPENAI_REVIEW_MODEL`(기본 `gpt-realtime-2.1-mini`)로 지정합니다.

음성 파일과 변환된 녹취 텍스트는 OpenAI API로 전송되어 처리됩니다. 실제 업무에 사용하기 전에 조직의 데이터 처리·보안 기준을 확인하세요. 앱은 로컬 주소 `127.0.0.1`에서만 실행됩니다.

## 문제 해결

- `.env` 키 오류: 파일에 `OPENAI_API_KEY=...` 형식으로 설정하고 앱을 다시 실행합니다.
- OpenAI 연결 오류: 실행 PC에서 `api.openai.com`으로 HTTPS(443) 통신이 가능한지 확인합니다. 회사 네트워크에서는 유효한 프록시나 방화벽 허용 설정이 필요할 수 있습니다.
- 대상 목록 또는 스크립트 오류: 두 파일이 `streamlit_app.py`와 같은 프로젝트 폴더에 있는지 확인합니다.
